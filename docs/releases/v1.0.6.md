## What's new

- Rebuilt the interface around a monochrome Cockpit with live driving instruments, fuel and lap data, and a compact radio dock.
- Reorganized Telemetry, Fuel & Strategy, Engineer & Spotter, AI & Voice, and System & Devices into dedicated workspaces while preserving existing controls and configuration options.
- Replaced the vehicle diagram with four FL/FR/RL/RR tiles showing tyre temperature, pressure and brake temperature, including correct zero and missing-data states.
- Added a new monochrome RaceEngineer identity across the app header, Windows application/tray/installer icons and both READMEs.
- Bundled static local fonts, increased text sizes outside the Dashboard, and adjusted the Cockpit layout to fit supported windows without scrolling.
- Restored opponent names and DirectInput binding readouts, fixed the voice-configuration shortcut, and kept unsaved form drafts when navigating between workspaces.
- Fixed long startup errors extending outside the window and unavailable-model API errors being displayed as successful connections.
- Reduced unnecessary UI work with workspaces loaded on demand, virtualized radio history, and live bindings suspended while their views are inactive or minimized. No native performance percentage is claimed.

Telemetry, race logic, voice backends, settings defaults and existing training/consent gates are unchanged. This release reorganizes their presentation.

AC Spotter requires the companion bundled under `extras/AssettoCorsa/apps/python/RaceEngineer`; copy it into Assetto Corsa's `apps/python` directory and restart the simulator. ACC opponent wheel geometry remains unavailable, so nearby-car Spotter reports unavailable there.

Live-track overlap calibration remains pending. Pit recommendations remain gated until calibration and independent race validation meet approval criteria.
