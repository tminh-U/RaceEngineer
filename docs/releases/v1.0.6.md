## What's new

- Fixed the Cockpit showing a waiting state despite receiving telemetry when AC/ACC track and car metadata arrives after the initial connection. Metadata is refreshed during the connection and missing static/graphics mappings are retried; connected cars without metadata no longer display instructions to start an already-connected simulator.
- Added automatic AC Python companion installation/enabling and ACC UDP setup during installation, with Steam-library discovery, backups and scoped elevation when the AC folder needs administrator access.
- Added a game-setup section in System & Devices to inspect AC/ACC configuration, choose an AC folder and install or repair the integrations. Configuration readiness is reported separately from live telemetry.
- Added an on-demand GitHub update checker, including detection of newer reissues with the same version number, and a link to download the installer.
- Rewrote the Quickstart for installer and portable users, including game setup, connection checks and manual app updates.
- Rebuilt the interface around a monochrome Cockpit with live driving instruments, fuel and lap data, and a compact radio dock.
- Reorganized Telemetry, Fuel & Strategy, Engineer & Spotter, AI & Voice, and System & Devices into dedicated workspaces while preserving existing controls and configuration options.
- Replaced the vehicle diagram with four FL/FR/RL/RR tiles showing tyre temperature, pressure and brake temperature, including correct zero and missing-data states.
- Added a new monochrome RaceEngineer identity across the app header, Windows application/tray/installer icons and both READMEs.
- Bundled static local fonts, increased text sizes outside the Dashboard, and adjusted the Cockpit layout to fit supported windows without scrolling.
- Restored opponent names and DirectInput binding readouts, fixed the voice-configuration shortcut, and kept unsaved form drafts when navigating between workspaces.
- Fixed long startup errors extending outside the window and unavailable-model API errors being displayed as successful connections.
- Reissued v1.0.6 on 2026-10-20 with a hollow circular disconnected-status marker, replacing the square that resembled a missing icon; connected status retains its filled circle.
- Made Windows release builds use a consistent AVX2 CPU baseline instead of inheriting AVX-512 from the build machine.
- Reduced unnecessary UI work with workspaces loaded on demand, virtualized radio history, and live bindings suspended while their views are inactive or minimized. No native performance percentage is claimed.

The Windows package requires an AVX2-capable CPU and a working Vulkan runtime/driver, including when CPU compute is selected.

Race algorithms, voice backends, app settings defaults and existing training/consent gates are unchanged. Game setup writes the required companion files and simulator configuration, preserving valid ACC ports/passwords and backing up files whose contents change.

Close AC/ACC before installing or repairing game integration. The installer automatically configures detected games; portable users can use System & Devices to do so. If AC is not detected, select its folder there. Restart the simulator after setup and enter a track to verify live telemetry. AC Spotter requires the bundled companion; ACC opponent wheel geometry remains unavailable, so nearby-car Spotter reports unavailable there.

Windows UAC consent and real AC/ACC sessions require verification on the user's machine; automated build/package checks do not establish live-game connectivity. The update checker opens GitHub Releases for a manual download and does not install updates automatically.

Live-track overlap calibration remains pending. Pit recommendations remain gated until calibration and independent race validation meet approval criteria.
